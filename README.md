一个简单的、遵循 Material 3 Expressive 的待办应用，使用 Jetpack Compose 编写

## 📦 版本支持

支持 `Android 7.0 (Nougat)` 至 `Android 16.0 (Baklava)`

## 📃 许可证

[GPL-3.0-only](https://github.com/Super12138/VerveDo/blob/main/LICENSE)

## ✨ 功能

- [x] Jetpack Compose
- [x] Material 3 **Expressive** 设计
- [x] 任务分类
- [x] 任务优先级
- [x] 数据备份
- [x] 时间划分功能
- ...
